# iSay releases

Signed builds of **iSay**, on-device Mandarin/English dictation for macOS (hold fn, talk, release).

- **Install:** download `iSay.dmg` from the [latest release](https://github.com/bluevisor/iSay-releases/releases/latest), drag iSay to Applications, then right-click → Open the first time.
- **Updates:** iSay checks this repository's `appcast.xml` daily and installs signed updates itself (Sparkle, EdDSA).

Needs macOS 26 on Apple silicon. Speech and cleanup models download on first launch and are managed in Settings → Models.
